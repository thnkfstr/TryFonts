Copyright (c) Ben Adams 2024
Open source license: GPL3 (https://github.com/ben-adams1/TryFonts/blob/main/LICENSE).


Enter any text string and see how it will look with different fonts applied.
Apply bold and italics or change the font size.
Search for fonts.

Runs locally and does not require an internet connection. There is no tracking.

I'm not actively developing this, but feel free to submit pull requests if you want to suggest changes or improvements.
